# DevelopAid 0.12.42

- Сначала проверяется ГлавАПУ для любого кадастрового номера, включая кадастры `50:` Новой Москвы.
- При успешном ответе используются официальные ТЭП ГлавАПУ.
- При отсутствии результата ГлавАПУ кадастр `50:` направляется в резервный расчёт Московской области.
- Кадастры других регионов не рассчитываются по нормативам Московской области: предлагается загрузка ТЭП или ручной ввод.
- Добавлены API-маршруты `/cadastral/route` и `/cadastral/mo-tep`.
- Версия приложения и команда `/status` обновляются до `0.12.42`.
