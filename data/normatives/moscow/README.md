# Москва — нормативный source pack

Этот каталог — единая точка входа в московские нормативы, влияющие на расчёты DevelopAid.

## Правило доверия

Карточка в `data/normatives/registry.json` отвечает за документ, редакцию, watcher и связь с движком. Этот source pack отвечает за содержательную норму: что регулирует акт, какие расчёты он меняет и что ещё нельзя считать подтверждённым.

Число нельзя переводить в hard FAIL только потому, что оно есть в старом коде или вторичном источнике. Для машинного правила нужны документ, действующая редакция, пункт/таблица и проверяемый источник.

- [1557-ПП](pp_1557_2020-09-22.md) — физическая культура и спорт.

## Текущий статус

Пакет создан как каркас содержательной ревизии. Наличие карточки не означает, что все таблицы акта уже перенесены в машинные reference-данные. Непроверенные редакции и нормы должны оставаться `review_required` / `manual_source_required`.

Особенно важно: 2150-ПП и 2151-ПП раньше отсутствовали в registry.json; они добавляются вместе с этим пакетом, чтобы социальная инфраструктура не выпадала из нормативного watcher.
