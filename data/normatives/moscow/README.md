# Москва — нормативный source pack

Этот каталог — единая точка входа в московские нормативы, влияющие на расчёты DevelopAid.

## Правило доверия

Карточка в `data/normatives/registry.json` отвечает за документ, редакцию, watcher и связь с движком. Этот source pack отвечает за содержательную норму: что регулирует акт, какие расчёты он меняет и что ещё нельзя считать подтверждённым.

Число нельзя переводить в hard FAIL только потому, что оно есть в старом коде или вторичном источнике. Для машинного правила нужны документ, действующая редакция, пункт/таблица и проверяемый источник.

## Текущий статус

Пакет создан как каркас содержательной ревизии. Наличие карточки не означает, что все таблицы акта уже перенесены в машинные reference-данные. Непроверенные редакции и нормы должны оставаться `review_required` / `manual_source_required`.

Особенно важно: 2150-ПП и 2151-ПП раньше отсутствовали в registry.json; они добавляются вместе с этим пакетом, чтобы социальная инфраструктура не выпадала из нормативного watcher.

## Иерархия источников

Для Москвы приоритет источников в source pack:
1. `mos.ru` и ведомственные поддомены `*.mos.ru`;
2. официальный портал Комплекса градостроительной политики и строительства `stroi.mos.ru`;
3. официальный градостроительный контур Москвы / Москомархитектуры;
4. `pravo.gov.ru` для федеральных актов;
5. Гарант/Консультант — только как резерв для поиска редакции и перекрёстной проверки, если официальный московский URL не даёт машиночитаемого текста.

Watcher должен хранить официальный URL там, где он найден и устойчив. Замена официального URL агрегатором только ради удобства чтения нежелательна.

## Контур нежилых объектов

Для нежилья нет одного универсального коэффициента озеленения на квадратный метр. Проверка строится каскадом:
`функция объекта → профильный НГП → ПЗЗ 120-ПП → ППТ/ГПЗУ → специальные СП/СанПиН/технические требования`.

Поэтому нормативный движок должен различать как минимум офис, торговлю, гостиницу/апарт-отель, образование, здравоохранение, спорт, производство/склады, культуру/досуг и встроенное нежильё в жилом комплексе. Если после прохождения каскада норматив площади территории/озеленения не установлен, результат — `not_universal / check_gpzu_pzz`, а не придуманное число.
