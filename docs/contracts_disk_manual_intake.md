# Обновление договорных источников с Яндекс.Диска

Проверка запускается вручную в Мониторе: «Данные и настройки» → «Источники договоров · Яндекс.Диск». Вставьте публичную ссылку на папку проекта и нажмите «Проверить Диск». Расписания и фоновые обходы не создаются.

Проверяются только существующие разделы «Юрист», «Сметчик» и «Общие по проекту». Результат отдельно перечисляет просмотренные и пропущенные разделы. «Служебные» (в том числе прежние папки ГПР), «Бухгалтер» и «Строитель» не просматриваются; число файлов в них неизвестно. Это не полный каталог Диска. Если новая структура ещё не создана, нужные файлы из старых разделов могут отсутствовать в результате.

В «Юристе» и «Сметчике» одинаковый путь:

`Роль / Контрагент / Номер договора / Тип документа / Исходный файл`

Типы: «Договор», «Дополнительные соглашения», «РДС», «ГПР», «КС-2», «КС-6а», «Акты передачи площадки». Слеш в номере заменяется подчёркиванием только в имени папки; реквизиты оригинала не меняются. Старые пути `Сметчик / КС-6 / Контрагент / Договор` и аналогичные пути с типом перед контрагентом также читаются. Общая сводная хранится в `Общие по проекту / Сводная по закрытию`.

Каталог показывает новые, изменённые, уже сохранённые и требующие сверки файлы. Выберите до20 исходников, затем «Проверить выбранные файлы». Исходники скачиваются по проверенной контрольной сумме и проходят штатный разбор. Это ещё не применение к Монитору.

«Применить проверенные файлы» передаёт подтверждённые по принадлежности PDF в существующие карточки, а накопительные Excel и общую сводную — в штатный импорт ZIP. Для КС-6а нужна отдельно указанная дата снимка. Дата изменения файла не считается датой выполнения. При конфликте уже действующего снимка прежний архив не удаляется и не заменяется автоматически.

Для существующего договора проверяется уникальная карточка и реквизиты внутри исходника. Папка сама по себе не подтверждает юридическую принадлежность. В PDF дополнительно нужны полные наименования сторон и явные цитаты об их ролях. Неоднозначные реквизиты и сканы остаются на сверке. Для нового договора сначала применяется штатный приём основного PDF с подтверждением сторон, номера и даты; папка не создаёт карточку автоматически.

Поддерживаются PDF договоров, ДС, РДС, ГПР, КС-2 и актов передачи; для КС-6а и общей сводной — XLS, XLSX и XLSM. XLSX в папке «ГПР» показывается как требующий отдельного поддерживаемого разбора, не пропускается и не принимается как КС-6а. Эта интеграция не добавляет новый парсер Excel-ГПР или сравнение численности.

Одинаковое содержимое в двух ролях одного договора — один источник. Одинаковый файл у разных договоров требует сверки. Ранее сохранённый или исключённый из расчёта источник не импортируется и не восстанавливается повторно. Новая версия сохраняется отдельно. Исчезновение файла с Диска не удаляет принятую версию Монитора.

Приём файла не подтверждает подпись или новую редакцию ГПР. Эти действия остаются в штатной карточке с проверкой точного источника. ДС без нового ГПР сохраняет прежний график. Выпуск этой интеграции требует действующей защиты новой редакции ГПР и совместимости подтверждений при обновлении PDF-читателя; отдельное принятие исходников не обходится.

Автоматический приём не восстанавливает исключённые источники, включая копии в исходных карточках одной семьи. Перед записью повторно проверяются состав семьи и текущее состояние под штатными блокировками. Ручное восстановление в обычной карточке остаётся отдельным действием.

Операционные карточки используют действующий штатный выбор источников: проверяются точные logical ID, решение, read guard и роли. PDF сохраняется только в выбранном источнике документов, а принадлежность КС-6а сверяется с выбранным источником выполнения. Цена, выполнение и документы не назначаются по одному имени папки. Устаревший или неподдерживаемый выбор требует сверки в карточке; новый файл не подтверждает и не обновляет это решение автоматически. Если первый файл изменил текущий guard карточки, остальные файлы этой карточки могут потребовать новой проверки каталога. Это не повторный импорт уже принятых исходников.
