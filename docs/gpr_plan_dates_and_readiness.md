# Плановые даты и готовность работ

Доля прошедшего календарного интервала не является плановой готовностью
по объёму работ. Для такой готовности нужно распределение плановых объёмов
по датам; одних начала и окончания недостаточно.

Матрица Монитора показывает датированное выполнение и исходные плановые
даты. Вычисленная по календарю доля не выводится как плановый процент
и не сравнивается с фактическим выполнением в процентных пунктах.
Исходные даты, факт и отдельный условный сценарий окончания сохраняются.
Поле API `plan_progress` остаётся прежним календарным показателем; матрица
хранит его только в диагностическом атрибуте `data-calendar-fraction`.

Проверки выполняют настоящий код страницы и настоящий Chromium на узком
и широком экране: `test_monitor_gpr_calendar_plan_label.py` и
`test_gpr_calendar_is_not_readiness.py`.
