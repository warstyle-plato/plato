# Ревизия внешнего вида DevelopAid и отчётов — 27.09.2026

Это ревизия: код не менялся. Здесь находки по блокам и план из 7 пакетов правок, по одному PR на пакет (в конце документа).

## Как смотрели

- **Прод developaid.ru (v0.24.51)**, Chromium через Playwright, 1440×900 и 390×844. На проде смотрели страницу без входа, импорт примера, каталог КРТ и торги.
- **Результаты и отчёты на проде закрыты входом через Telegram.** Поэтому заполненный отчёт, PDF и книгу сняли с локального запуска того же кода: `uvicorn main_registry:app`, **v0.24.52**, без токена бота, так что вход выключен. Между этими версиями одно отличие — #547 (тизер). Пример проекта «Румянцево» (кнопка «Открыть пример» → «Применить» → «Пересчитать модель»).
- Всё проверяли на отрисованной странице: тексты брали `innerText`, переполнение на телефоне мерили через `getBoundingClientRect` и `scrollWidth`. PDF разобран через PyMuPDF, книга v4 — через openpyxl (формулы не вычислялись, смотрели состав и порядок).
- Снимки лежат в `docs/ui_audit/`. Префикс `d_` — десктоп, `m_` — 390 px, `pdf_` — страницы PDF. Снимки с `_r_`, `_in_` и `pdf_` сделаны локально (0.24.52), остальные — на проде.

**Важность:** 🔴 мешает считать или понимать · 🟠 неудобно · ⚪ косметика.
Где находка похожа на ошибку в числе, а не только в подписи, стоит пометка **«проверить число»**: такую находку надо сначала разобрать у владельца числа, а не просто переименовывать.
