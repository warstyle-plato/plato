# DevelopAid 2.0 — контрольный прототип

## Назначение

Прототип добавляет новый мобильный и desktop-интерфейс к действующему DevelopAid без изменения расчётного движка, Excel, PDF, Telegram-логики и формул.

Маршрут прототипа: `/v2`.

Контрольные проекты:

- **Мишина** — компактный проект Москвы без включённой очередности;
- **Мытищи** — крупный проект Московской области, 22 участка, три очереди и офисы в третьей очереди.

## Изоляция от production-логики

`main_registry.py` устанавливает дополнительный модуль `developaid_v2.py`. Модуль регистрирует только новые маршруты:

- `GET /v2`;
- `GET /v2/assets/styles.css`;
- `GET /v2/assets/app.js`;
- `GET /api/v2/projects`;
- `GET /api/v2/projects/{slug}`.

Существующие маршруты и расчёты не заменяются.

## Что реализовано

- переключение Мишина / Мытищи;
- адаптивный тёмный интерфейс;
- Summary с KPI и инвестиционным выводом;
- ТЭП и ВРИ;
- БРИДЖ, ПФ и эскроу;
- очереди и календарные полосы;
- Tornado по LLCR;
- концептуальный экран Платона;
- desktop и mobile layout;
- контрольные тесты состава данных и статических файлов.

## Статус данных

Первая итерация использует контрольные показатели из утверждённых PDF DevelopAid от 02.08.2026. Временные ряды графиков являются визуальными прототипами и не должны использоваться для инвестиционных выводов.

На следующем этапе контрольные fixtures заменяются адаптером к единому результату расчётного движка. После этого `/v2` будет отображать тот же объект результата, из которого формируются Excel и PDF.
