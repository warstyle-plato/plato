# «Пульс»: API всероссийского кабинета

Продолжение `docs/pulse_subdomain_access.md`. Снято вживую 11.10.2026: вход
формой `pulsprodaj.ru/accounts/login/`, затем `russia.pulsprodaj.ru/map` с
той же банкой кук. Код — `market_search/pulse_russia.py` (`PulseRussiaClient`),
образцы ответов — `tests/fixtures/pulse_russia/`.

## Что было не так

Кабинет — одностраничное приложение: `/map` отдаёт 850 байт и скрипт
`/assets/index-*.js`. Встроенного GeoJSON нет, московские адреса (`/map/`,
`/api/search/`, `/api/app/complex/price_stats/`, `/sales/`) отвечают 404.
Скрипт ходит на `${API_URL}/api/v1/…` (`API_URL` = `https://russia.pulsprodaj.ru`)
двумя обёртками: `POST` с JSON и заголовком `X-CSRFToken` из куки
`csrftoken`, и `GET`. Сессия — кука `sessionid` корневой базы (и
`shared_session` на `.pulsprodaj.ru`).

## Маршруты, которыми мы пользуемся

| Что | Запрос | Ответ |
|---|---|---|
| Номер региона кабинета | `POST regions/search/` `{"query": "Московская область", "excludeIds": [], "limit": 20}` | дерево округ → субъект → городские округа; `id` субъекта (`level: 1`) |
| ЖК региона с точками | `POST search/` `{"regionsIds": [9], "filters": [{}], "entityType": "complex"}` | `content`: `{id: {name, object_count, lat, lon, map_status, is_owned}}` |
| Карточки ЖК | `POST objects_grouped/` `{"ids": [], "group_by": "complex", "complex_ids": [...]}` | строка на ЖК: `complex_id`, `object_ids`, `object_class`, адрес, застройщик, `actual_living_remaining(_area)` |
| Цена | `POST aggregator-card-data/` `{"ids": [], "complex_ids": [id], "object_type": "living"}` | `table` — проект на площадке (ЦИАН/Яндекс/Домклик): `price_date`, `count_price`, `sqm_price`, `code`; `history` — помесячные ряды `aggregator_*` |
| Темп | `POST objects_sales_summary/` `{"ids": [объекты ЖК]}` | `cols[key=living]`: `avg_units`, `avg_area` за `period_start…period_end`, остатки |

Прочее, что есть в скрипте и пока не используется: `objects_info/`
(объекты целиком, без номера ЖК), `object/{id}/`, `complex/{id}/`
(в т.ч. `ppn_complex_id` — номер того же ЖК в московском кабинете),
`deals_summary/`, `graph/`, `aggregator-graph/`, `filters_parameters/`,
`object_fields/`, `statistics/`.

## Решения

- **Регион кабинета — не код субъекта.** «50» у кабинета — Астраханская
  область, Московская — «9». Номер ищется по названию из `REGION_NAMES` и
  кладётся в `regions.json`. Справочник собирается по регионам
  `PULSE_REGIONS` (по умолчанию 50) — запрос `search/` на регион.
- **Единица — ЖК.** Объект строительства (`50-003285-1`) — корпус; соседом
  и проектом свода считается ЖК, иначе один ЖК из трёх корпусов был бы тремя
  соседями с одной и той же ценой. Наш номер ЖК — `50-c350624` (код региона,
  буква «c», внутренний номер). `pulse_region` читает из него регион,
  `pulse_declaration` — ничего: у ЖК нет одной декларации.
- **Один ЖК, несколько записей.** Кабинет иногда делит ЖК на записи
  («Ярославский» — три). Объекты у записей разные, но объявления бывают
  общие. Цена несёт коды проектов площадок (`listings`); запись, чьи коды уже
  взяты ближним соседом или проектом свода, — тот же ЖК, а не ещё одна цена
  (`same_listing` в `peer_search`, «те же объявления» в своде).
- **Класс** — `object_class` карточки, переведённый картой
  `pulse.RUSSIA_CLASSES` / `pulse_class` (один владелец для соседей и свода):
  Типовой → «Комфорт» (решение владельца 13.10.2026; 12.10 было
  «Стандарт/Эконом»), Комфорт,
  Бизнес, Премиум, Элитный → «Элит/De Luxe». Склейка «Типовой, Комфорт» и
  слово вне карты («Другое») — не класс, а «не знаем» (сырой текст — в
  `segment_raw`; незнакомые слова — `coverage.unknown_classes` свода).
  Свод несёт карту, по которой разложен (`class_map`); свод по другой карте
  (в том числе собранный до неё) считается устаревшим и собирается сразу.
- **Цена — объявления агрегаторов, а не прайс-лист.** Последняя дата;
  площадка с наибольшим числом лотов (площадки показывают одни и те же
  квартиры — лоты не складываются); проекты одной площадки внутри ЖК
  складываются с весом по лотам. Границы — по всем площадкам на эту дату.
  Цена старше полугода (`_fresh_price_since`) — не цена «на дату сбора»: в
  своде она не участвует (`coverage.stale_price`), у соседей помечается.
- **Класс места по соседям** голосуют соседи с действующей ценой
  (`_class_of_place`): у кабинета класс есть и у домов 2010 года.
- **Московский кабинет в покрытом регионе молчит.** Он знает ЖК области под
  своим номером («Атлантис» — 4033) и отвечает на их цену 403. Проект другой
  базы снимается, если его регион (код номера или область адреса, в том
  числе «МО, …») покрыт всероссийским кабинетом: `superseded_by_russia` в
  отчёте справочника. Адрес без области («г.о. Мытищи, мкр.10-10а…» у
  «Атлантиса») регион даёт двойник: ЖК всероссийского кабинета с тем же
  названием (`same_project`) не дальше `TWIN_KM` (300 м).
- **Нагрузка.** Справочник: запрос региона + `search/` + карточки пачками по
  50 ЖК (на МО — 14 запросов в сутки). Цена и темп — по запросу на ЖК, с
  кэшем на 12 часов; пустой ответ не кэшируется, обрыв связи повторяется
  один раз. Недельный свод спрашивает темп только у ЖК с ценой.
- **Подписка.** Ответ с `subscription_required` или `access_restricted`
  называется в `errors` прямо: «закрыты подпиской кабинета».

  регионе 50 сняты как дубли.

  (Бархат 333 673 ₽/м², Атлантис 258 636, Мытищи-Сити 260 365, КИТ 2-я

  219 119 (101), Бизнес 279 175 (25); муниципалитетов — 35. Подсказка цены
  у участка без соседей в радиусе: «по классу: Московская область».
