# Неиспользованные строки реестра платежей

Шаблон РСС может содержать заранее заполненную формулу поиска наименования
работы в колонке H. При отсутствии кода она сохраняет числовой ноль.
Если остальные читаемые поля платежа пусты, такая строка не подтверждает
существование платежа и не входит в обычную или строгую проекцию.

Правило касается только числового нуля в наименовании работы при полностью
пустых остальных полях. Сумма 0 в колонке J остаётся наблюдением строгого
читателя. Возвраты и строки с любым другим реквизитом, неизвестной суммой
или датой сохраняются. Неизвестные суммы не заменяются нулями; отсутствие
шаблонных строк само по себе не подтверждает полноту реестра.

Регрессии `tests/test_payment_template_rows.py` читают XLSX с настоящей
формулой и сохранённым результатом 0, проверяют обе проекции, возврат,
нулевую сумму, неполные строки и итог оплаты конкретного договора.

## Реквизиты непрочитанного платежа

Обычные финансовые ответы Монитора и сводки сохраняют в неполных строках
`sheet`, `payment_context` и `amount_cell`. Контекст содержит прочитанные
реквизиты договора, объекта, назначения, кода, даты и источника денег. У суммы
сохраняются координата `J<строка>`, тип, состояние и ограниченное исходное
скалярное значение. Строка суммы ограничена 256 символами, строки контекста —
512; усечение отмечено явно. Это происхождение записи, а не новый расчёт.

`missing_saved_value` означает, что читатель с `data_only=True` получил
`None`. По этому наблюдению нельзя отличить пустую ячейку от формулы без
сохранённого результата. Формулы не вычисляются и повторно не открываются.
Для прежних DTO без наблюдения указывается `not_captured`, без догадки по
уже нормализованной сумме. Нечисловое и неполное значение остаётся неизвестным.

Наблюдение берётся при прежнем чтении реестра и хранится в том же кэше.
`read_payments(..., include_cell_metadata=True)` включает его для двух
финансовых читателей; оба прежних режима по умолчанию сохраняют состав полей.
В обычный финансовый ответ контекст попадает только у неполных строк.
Суммы, знаки возвратов, даты, охват глав и критерии полноты не меняются.
