## Почему 57,8% не равно 34,6%

Это разные потоки, а не два способа печати одного результата.

* Движок с DEFAULT_INPUTS и явно выбранным ориентиром hotel1:
  начало 01.01.2027, ввод 01.07.2030, конец 01.06.2045;
  CAPEX 4 954,319 млн ₽ с НДС, IRR проекта 20,4934%,
  equity IRR 57,7695%, пик капитала 313,086 млн ₽,
  пик долга 4 259,348 млн ₽, погашение 01.10.2034.
* Источник: «Контр_панель»!G20 = IRR_Equity = «Расчеты»!E1689,
  `IRR(L1682:AY1682)` = 34,6345%. Строка 1682 суммирует по годам
  квартальные потоки строки 1679. Поэтому шаг самого IRR — **годовой**;
  операционные расчёты книги квартальные. G14 = E1651 =
  `IRR(L1645:AY1645)` = 17,6813%.
* CAPEX источника: G66 (отель) 4 183,467 млн ₽ **без НДС** плюс
  G71 (коммунальная инфраструктура) 1 370,989 млн ₽; G74 =
  5 554,456 млн ₽ без НДС. С НДС E775 это 6 776,436 млн ₽,
  на 1 822,117 млн ₽ больше CAPEX варианта движка.
* Книга начинается 01.10.2025, ввод — 01.01.2029. Первоначальная
  потребность в капитале L1381 составляет 261,703 млн ₽;
  выборка старшего долга L1382 равна нулю. Дальнейшие выборки определяются
  флагом L1399 и фактическим рычагом строки 1383. Движок распределяет долю
  кредита по затратам своим помесячным графиком. Одно значение E703 =
  96,562% не делает эти графики финансирования одинаковыми.
* Терминальная стоимость книги — Гордон: L1641 для проекта и L1678
  для капитала используют поток последних четырёх кварталов × (1+g)
  / (Required_Rate_of_Return−g); у капитала добавляется Cash_EoP.
  Ориентир движка задаёт EV/EBITDA = E758 = 4, продажу, затраты выхода
  и налог. E759 = «да» означает включение терминальной стоимости,
  а не тождество её формулы мультипликатору.

Диагностический мост на существующем стенде
`tests/test_hotel_dombai_svod.py`: при подаче исходного CAPEX по кварталам,
исходной мебели, ключевой ставки и дат книги equity IRR движка составляет
40,8344% при продаже или 41,1076% при удержании. Годовая агрегация этих
же потоков даёт 40,8980% и 41,2087%. Следовательно, только частота IRR
разницу до 34,6345% не объясняет; большая часть изменения от 57,7695%
связана с заменой исходных затрат, дат и ставки. Остаток содержит отличия
выхода, выборки кредита, налога и оборотного капитала, перечисленные в
`hotel_reference_benchmarks.md`. Полного тождества с исходной книгой нет.

Воспроизведение моста из корня ветки:

```python
import sys
sys.path.insert(0, 'tests')
from test_hotel_dombai_svod import run
for mode in ('sale', 'hold'):
    print(mode, run({'exit_mode': mode})['kpi']['irr_equity'])
```

Методология и эталоны не изменялись. Подгонять поток или допуски под 34,6%
без отдельного решения владельца нельзя. Это ограничение сопоставимости
при выпуске, а не доказанный дефект вычисления IRR.
