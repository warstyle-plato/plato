# Пятна домов из схемы города для объёмной схемы застройки — разведка источника

Задание владельца (23.10.2026): для проектов, у которых есть городская схема
(пример — КРТ «Нагатино», Варшавское ш., влд. 37 / Нагатинская ул., влд. 3А/6),
рисовать дома на объёмной схеме (`engine/site_massing_layout.py` →
`tep.site_massing.scheme`) по пятнам города, а не нашей расстановкой. Картинка
из презентации без координат не годится — нужен векторный источник.

## Итог

**Надёжного векторного источника с пятнами домов для КРТ «Нагатино» сейчас нет.**
Причина не в нашем маршруте, а в стадии проекта: юридически пятна (зоны
планируемого размещения ОКС с этажностью и назначением) появляются только в
утверждённом проекте планировки территории (ППТ), а ППТ по КРТ готовит
победитель торгов **после** заключения договора. Проект решения о КРТ прямо
это говорит (п. 8): «Предельный срок подготовки документации по планировке
территории … составляет 12 месяцев со дня заключения договора о КРТ». Схема,
которую прислал владелец, — это архитектурно-градостроительная проработка
(концепция) из материалов КРТ, а не утверждённый документ; в открытом виде её
вектора нет.

## Что было бы в источнике, когда ППТ появится

В московском ППТ (постановление Правительства Москвы, порядок — 270-ПП) есть
«Чертёж планировки территории» с **номерами зон/участков** и таблица
«Характеристики объектов капитального строительства» по тем же номерам:
назначение (жильё, школа, ДОО, нежилое), суммарная поэтажная площадь,
предельная высота/этажность, иногда очерёдность. Публикуется как PDF на mos.ru:
чертёж — растр. Вектор есть только в ИАИС ОГД.

Важно для встраивания: ППТ в Москве задаёт **зону размещения**, а не контур
дома. Пятно внутри зоны всё равно расставляет архитектор, поэтому даже
утверждённый ППТ даст не «дома как у города», а рамку, в которую наша
расстановка обязана уложиться.

## Как связывать с нашими корпусами (когда источник будет)

- Ключ — номер зоны из чертежа ППТ и та же строка таблицы характеристик. Корпус
  хранит `ppt_zone_id`; соответствие задаётся явной картой, а не порядком,
  размером или соседством (CLAUDE.md: не угадывать схему по позиции).
- Корпус без номера зоны — «не привязан», а не «зона 1».
- Назначение берётся из таблицы ППТ по номеру, не по цвету пятна на картинке.

## Свежесть

- Хранить номер и дату постановления об утверждении ППТ и дату выгрузки.
- Проверка актуальности: перед использованием сверять, не вышло ли
  постановление об изменении ППТ (тот же номер территории, более поздняя дата);
  при неизвестном статусе схема помечается «не проверена на изменения», а не
  выдаётся как действующая.
- Сменился ППТ — пересчитать зависимые величины (CLAUDE.md: производное число
  не замораживать).

## Ограничения разведки

- Каталог слоёв НСПД снят с кадастровой карты (тема ПКК). Другие тематические
  карты НСПД (градостроительная деятельность / ГИСОГД РФ) перебором не
  проходились: номеров их слоёв у нас нет. Если такой слой существует, его номер
  снимается тем же способом, что 17–18.08.2026 (включить слой на карте НСПД и
  прочитать wms-запрос / консоль), затем `/land/screen-probe?layers=имя=номер`.
  Для «Нагатино» он всё равно будет пуст, пока ППТ не утверждён.
- isogd.mos.ru, data.mos.ru, egip.mos.ru из песочницы недоступны; вывод о них —
  по поиску, а не по живому ответу.

## Предложение

1. Сейчас кода не писать: источника нет, а растровая схема без координат
   нарушает правило «не угадывать схему».
2. Если владелец получит вектор (DWG/DXF/MIF из ИАИС ОГД или от архитектора
   концепции с координатами МСК-77/WGS-84) — принять его загрузкой файла:
   контуры + таблица «номер → назначение, этажность», с происхождением
   «схема владельца, файл, дата». Это даёт пятна и для проектов до ППТ.
3. Когда по КРТ утвердят ППТ — зоны размещения как рамка: наша расстановка
   кладёт корпуса внутрь зоны с её этажностью, номер зоны — явный ключ.
