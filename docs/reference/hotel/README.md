# Эталонные финансовые модели гостиниц

Присланы владельцем как образцы эксплуатационной модели гостиницы
(не РНГП и не нормативы). Не секретны, разрешены к хранению в репозитории.

| Файл | Что внутри |
|---|---|
| `dombai_ski_hotel_5star_2025.xlsm` | Отель 1: горнолыжный отель 5* (модель от 2025-12-15): Предпосылки, Расчеты, USALI (Q/Y), Отчетность, Свод, Финансирование, Инвестор, Бюджетная эффективность |
| `arkhyz_sinara_2022.xlsx` | Архыз / Синара, 2022: Отель 3–5*, Резиденции, Хостел, Шале, Турпоток, ШР, CF, WACC, Sensitivity, KPI, Строительство, Амортизация |
| `uai_hotel_5star_200.xlsm` | Отель 2: гостиница 5*, 200 номеров: Анализ рынка, Конкурентный анализ, Загрузка, Штатное расписание, Предпосылки, Расчеты, Отчетность, Финансирование |
| `uai_cottage_hotel_5star_200_2025-01-14.xlsm` | Отель 3: отель в коттеджах 5* (в имени «200», в модели 120 вилл — «Предпосылки» E111): Загрузка, численность гостей, ADR поквартально, понижающий коэффициент, Штатное расписание |

Использование: источник ориентиров (ADR, загрузка, CAPEX/номер, штат/номер,
доли расходов по USALI) и сверка будущей эксплуатационной модели гостиницы.
Каждое перенесённое в код значение хранит происхождение: файл, лист, ячейка.
Формулы openpyxl не вычисляет — значения читать из сохранённых Excel итогов
(`data_only=True`).

Разбор и ориентиры с адресами ячеек: `docs/hotel_reference_benchmarks.md`;
машинная сторона — `hotel_reference.py` (сверяется с книгами тестом
`tests/test_hotel_reference.py`).
