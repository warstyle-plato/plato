# Договоры: редакции остатка и раздельные работы/материалы

Поручение владельца17.11.2026: убрать лишнюю оговорку из распознанного ГПР,
проверить заниженную готовность и отдельно учитывать материалы договора.

Ветка: `fix/contracts-chart-note-nur-readiness-20261117`.
Зависимость: существующий PR#1174 (`cc49e5b8`) с отображением охвата и границ
прогноза. Эта ветка дополняет его; чужая ветка не изменялась.

Состав: сохранение начала явно продолжающегося остаточного приложения и его
источника; независимые количества/цены работы и материала; физические веса
без материалов; отдельные материалы в карточке; явные пропуски актов и данных.
Полная цена договора сохраняется. Неполные источники не дополняются догадкой.

Реальные сохранённые разборы проверяются локально без записи в prod;
частные receipts и первичные документы в репозиторий не входят.
Авторские проверки и независимая приёмка фиксируются на конечном HEAD.
Выпуск возможен после проверок и штатной очереди; эта запись его не подтверждает.

Уточнение источника: повторяющиеся явные номера актов из версий одной КС-6а
дедуплицируются только при совпадении реквизитов работы, родного источника и
всех раздельных количеств/сумм. Новые периоды сохраняются, конфликтующие
значения остаются на проверке. Исходные недатированные итоги сохраняются для
проверки дат актами после сверки с периодами. Сам архив не задаёт дату работ.
Материалы из подписанных граф КС-6а показаны отдельно от факта работ по КС-2;
сводная по закрытию не является источником количеств или стоимости материалов.
