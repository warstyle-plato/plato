# Целостность импорта тизеров

Поручение владельца: реализовать найденные при ревизии ошибки распознавания
PDF, фото и ссылок и передачи параметров в движок, представить исправления в PR.

Ветка: `codex/teaser-intake-integrity`. База: `862a7bfd`.
Область: document intake, проверка доказательств, серверная карточка, PDF/OCR,
фото-ТЭП, публичный HTTPS-источник, классический интерфейс, `/v2`, Telegram.
Расчётные и нормативные формулы не меняются; преобразование единиц и связанные
площади выполняются сервером через существующие функции.

Приёмка: ошибочная цитата/число/единица/валюта не становятся фактом источника;
конфликт требует выбора; непроверенные суммы вопросов требуют ручного ввода;
карточка перед применением сверяется с текущими вводными и владельцем;
подтверждённые исходные клетки сохраняются без повторного пересчёта старым UI;
смешанный PDF и все кадастры не теряются молча; фото не сдвигает пустые клетки;
загрузка URL проверяет каждый переход и общий срок.

Проверки и текущий точный source HEAD фиксируются в PR. Независимая проверка
выполняется отдельным рецензентом, не авторами модулей.

Ограничения: реальные закрытые документы, Safari и качество OCR/LLM на
производственной выборке этой регрессией не измеряются. URL поддерживает
публичные прямые файлы и static HTML; auth/cloud preview/JS shell дают отказ
с предложением приложить файл. Таблица фото — явный пользовательский ввод,
а не сохранённая серверная OCR-аттестация. Запрос владельца в этом разговоре — PR.
