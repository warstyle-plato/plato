## Правка

- Клиент и объединённый справочник замечают замену файла по mtime_ns,
  размеру и inode; сетевое чтение учитывает суточный срок. `fetch=False`
  читает диск без сети, в том числе после истечения срока.
- Прямое обращение за ценой перепроверяет базу-владельца после обновления.
- GET/POST API поддомена повторяют вход на основной базе один раз перед
  окончательным отказом; успешный JSON снимает прежнюю причину закрытия.
- JSON пишется через уникальный временный файл и атомарную замену: два
  процесса не делят один `.tmp`, неудачная сериализация сохраняет старый файл.
- Ключи, права доступа, список регионов и ручная выдача версии не менялись.
