# Переданные постановления МО — отдельные строки справочника

Поручение владельца: 1420-ПП, 1860-ПП и 1310-ПП отсутствуют в списке
https://developaid.ru/normatives. Ветка `codex/mo-normatives-documents`.

Выпускается только справочник: три отдельные карточки, источники, цитаты,
даты и явные пределы подтверждения. Расчётные формулы не меняются.
1420-ПП раньше был внутри карточки 713/30; 1310-ПП подготовлен только в
невыпущенном PR #1086 вместе с денежной реализацией. Источники выводятся
отдельно, без переноса этой реализации и без утверждения о её приёмке.

1310-ПП прочитан по тому же скану, что в #1086 (SHA-256 совпал).
Дополнительно прочитана официальная карточка mosreg.ru с публикацией
15.10.2026 в 18:45, поэтому по п. 3 дата вступления в силу — 16.10.2026.
Ранее в #1086 календарная дата оставалась неподтверждённой.
У 1860-ПП опубликованная исходная редакция не подменяет последующие
294-ПП и 932-ПП; актуальный консолидированный текст не подтверждён.

Независимая приёмка должна проверить состав трёх видимых карточек,
реквизиты, цитаты по реальным PDF и отсутствие ложного утверждения
о реализованном вычете Ксу*. После приёмки — полный CI и штатный выпуск.
При возобновлении #1086 сохранить новые карточки и границы подтверждения;
противоречащие сведения о датах и реализации из старой ветки не возвращать.
