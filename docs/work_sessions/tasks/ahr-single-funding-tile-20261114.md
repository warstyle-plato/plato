# Одна плашка потребности с АХР

Поручение владельца: убрать отдельные плашки АХР, добавить оставшиеся АХР
в потребность допфинансирования и назвать эту часть внутри единственной плашки.
Заменяет требование четырёх основных плашек из
`ahr-visible-summary-20261113.md`; отдельной очереди выпуска нет.

## Результат

Сводка HTML/PDF показывает одну основную плашку потребности. Наблюдаемый
остаток АХР после учтённых оплат сохраняется как отдельное пояснение в ней;
полнота оплат с начала проекта не подтверждена, поэтому общий итог остаётся
неизвестным. `remaining_need=None` не заменяется этим остатком, в том числе
при нулевой потребности по другим главам. Четыре cash-плашки убраны с обложки;
в Мониторе исходные суммы и охват платежей остаются в раскрываемых деталях,
в PDF и при печати они раскрываются вместе с контекстом сохранённой ФМ.

Исходный расчёт по главам и выделенный в нём вклад АХР не меняются. Они
сами по себе не подтверждают полноту оплат АХР. Без принятой потребности АХР,
полного охвата оплат и проверенного разделения банковского расчёта численный
общий итог не заявляется. При отсутствии cash-данных сохраняется прежний
расчёт по смете банка с явным пояснением об отсутствии уточнения АХР.
Банковские лимиты, оплаты, waterfall, налоги и классификатор не меняются.

## Проверка и выпуск

Проверки включают обычную главу, замену графиком, статьи вне глав,
частичное/полное погашение плана, отсутствие данных, перерасход, неизвестный общий итог
в HTML/тексте, Монитор и сводку при 390/1440 px, PDF без четырёх плашек.
Все наборы синтетические. Реальные сохранённые книги проекта со скриншота
в этой среде отсутствуют; предметная сверка этого набора остаётся допуском
выпуска. Банковская сверка #1045 этой правкой не закрывается. Требуются
независимая проверка итогового HEAD и полный CI. Выпуск не аттестуется автором патча.

Приёмка ремонта привязана к точному итоговому HEAD и независимой проверке.
Сохранённый ограниченный DTO позволяет проверить только наблюдаемые АХР и
их отображение; он не содержит актуального банковского расчёта и полного
покрытия оплат с начала проекта. Его воспроизведение не закрывает финансовую
приёмку общего итога.
