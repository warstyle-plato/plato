# Одна плашка потребности с АХР

Поручение владельца: убрать отдельные плашки АХР, добавить оставшиеся АХР
в потребность допфинансирования и назвать эту часть внутри единственной плашки.
Заменяет требование четырёх основных плашек из
`ahr-visible-summary-20261113.md`; отдельной очереди выпуска нет.

## Результат

Сводка HTML/PDF показывает одну существующую плашку потребности. Её сумма
включает положительный остаток бюджета АХР после учтённых оплат, пояснение
называет эту часть и предварительный характер расчёта. Четыре cash-плашки
убраны. В Мониторе общий итог показан над раскрываемой расшифровкой АХР;
исходные суммы и охват платежей остаются в деталях.

АХР, уже включённые в прежний расчёт по главам, сначала исключаются из
потребности. Для обычной главы это разница остаточного плана с АХР и без
них при одинаковом зачёте оплат; для главы графика финансирования вклад
нулевой; для расходов вне глав — весь ранее учтённый бюджет АХР. Исходные
банковские лимиты, оплаты, waterfall и сверка по главам не меняются.

Неизвестный остаток АХР не становится нулём: прежняя потребность остаётся
с пояснением, что АХР ещё не уточнены. При известном остатке АХР и неизвестном
вкладе в прежний расчёт общий итог не объявляется известным. Перерасход АХР
не уменьшает общую потребность. `remaining_need=None` и прежние источники
оплат сохраняются.
