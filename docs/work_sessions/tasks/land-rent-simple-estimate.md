# Аренда земли: простой ввод и уточнения договора

Продолжение поручения владельца в существующем контроле
[#1019](https://github.com/warstyle-plato/plato/issues/1019).
Контроль — Codex согласно `CONTROL_ACTIVE`; рабочий продолжатель готовит патч
и авторские проверки, без самостоятельного слияния и выпуска.
Ветка: `codex/land-rent-result-clarity-20261112`.
База: `c3d92592a5aeac11799cae0fa82cc303b1f38506`.

## Требование владельца

Первый расчёт должен получаться по простой схеме без анкеты условий Москвы
и Подмосковья. Данные по умолчанию видны, пользователь может их изменить.
Уточнения договора доступны отдельно. Неизвестные данные не выдаются за ноль.

## Подготовленный вариант

- Регион определяется по применённому участку, кадастровая стоимость берётся
  из ЕГРН с прежним происхождением. Для нового регионального режима применяются
  прежние ставки движка, начало проекта и сценарные даты ввода. Если кадастра
  нет, поле объясняет источник и единицы. Ставки и суммы не выдумываются.
- При первом автоматическом выборе режима МО отсутствующие будущие индексы
  получают 0% с происхождением `default_estimate`: оценка в текущих ценах.
  Сохранённые значения, явно пустые ячейки и прошлые индексы не заменяются.
  Сохранённый режим МО можно явно перевести к такой оценке отдельной кнопкой.
  После изменения сроков добавляются только отсутствующие будущие годы.
- Движок относит используемые индексы `default_estimate` к финансовым
  уточнениям (`indices_estimate`), сохраняет предварительность и пояснение.
  Это не утверждённая индексация и не подтверждение применимости ставки 6%.
  Проверки дат договора, собственника земли, торгов/КРТ и региона сохранены.
- Договор, индексы, ВРИ, оплата и сроки находятся в раскрытии «Уточнить расчёт».
  Московские вопросы первого года не показываются в новом режиме МО;
  сохранённое нестандартное решение по первому году остаётся доступным для
  проверки. Право собственности не показывает анкету аренды.
- Строка «Аренда земли участка» сохраняет общий ответ движка
  `summary.land_rent_sum`, уже применённый в main:
  различает известную сумму, неизвестность, известную часть и неприменимость.
  Небольшая сумма не округляется до нуля миллиардов; оговорка стоит у числа.
- Заголовок решения одинаков до подбора цены, после него и в документах.
  При известной аренде по `summary.land_rent_sum` показывает результат проверки экономики с префиксом
  «Предварительно»; положительный результат остаётся жёлтым. Неизвестная
  аренда не считается бесплатным участком, предупреждение сохраняется.
