# АХР: сохранённый бюджет минус учтённые оплаты

Продолжение #1105 по поручению владельца. Текущий результат — четыре
основные плашки: бюджет АХР по сохранённой ФМ, учтённые оплаты АХР,
остаток после учтённых оплат и перерасход по учтённым оплатам. Контроль
очереди, независимая приёмка и выпуск остаются в #1019; новой очереди нет.
Полная банковская сверка #1045 — отдельный незакрытый предметный допуск.

## Бюджет и контекст ФМ

Бюджет — сумма листовых строк 2.4 без налоговой ветки 2.4.5 на cf_1_new.
Для неё сохраняется существующий нативный контракт финансового reader:
значения книги в тысячах переводятся в рубли один раз. Это контракт уже
работающего бюджетного чтения, а не новое подтверждение единиц по шапке,
не пользовательская декларация и не изменённые исходные данные.

Три прежние колонки ИТОГО / ФАКТ / ПЛАН остаются отдельным контекстом
«Данные ФМ». Их проекция и наблюдаемые единицы не меняются: нет однозначной
единицы — нет рублёвой суммы в этом контексте. Неизвестная дата версии
не выводится из имени, mtime или даты загрузки; raw_saved_snapshot,
cut_eligibility и amounts_at_cut сохраняют прежний смысл. Известная будущая
версия не выдаётся этим представлением за исторический факт. ФАКТ ФМ
не называется оплатой РСС или месячного бюджета.

Родитель 2.4 — только диагностика состава: три его скаляра сравниваются
с листовыми АХР без налоговой ветки и отдельно со всеми листьями, включая
налоги 2.4.5. Ожидаемое включение налогов в родителя не объявляется ошибкой.
Родитель не заменяет определение бюджета. Налоги и финансирование
не добавляются к АХР. Суммы сохраняют смысл источников; отдельного
подтверждения состава НДС или его перерасчёта эта стадия не даёт.

## Оплаты и неполнота

Оплаты РСС распределяет существующий payments_by_article в статью
project_management. Точная дата платежа проверяется до группировки
по месяцам. Основание распределения по договору, только по контрагенту
или только по коду сохраняется; неоднозначные потенциальные АХР остаются
неизвестными. Смешанная глава РСС 2.6 целиком не становится АХР.
Возвраты сохраняют знак. Подозрительно одинаковые строки не удаляются
молча и сопровождаются признаком возможного дубля в охвате АХР.

Факт АХР из месячных бюджетов читается по явной месячной колонке ФАКТ.
За один месяц выбирается последний загруженный подходящий файл, как
в нативном месячном reader. Его явный ноль сохраняется; NULL не заменяется
фактом более старого файла. Для законченного месяца факт АХР бюджета
заменяет оплаты РСС этого же месяца, а не складывается с ними. Скаляру
текущего незаконченного месяца без датированных платежей не приписывается
точность до выбранного дня. История не ограничивается двенадцатью месяцами.

Известная часть оплат видна и при пробелах. Подписанный промежуточный
остаток равен сохранённому бюджету минус учтённые оплаты; перерасход
определяется по этому же остатку. Неизвестность не становится нулём.
Подтверждённая потребность remaining_need остаётся неизвестной без допуска
полноты истории с начала проекта. Промежуточный остаток не объявляется
подтверждённой потребностью или доказанной верхней/нижней границей.

Отказ РСС не гасит читаемые ФМ и месячные бюджеты, отказ бюджетной части
ФМ не гасит её читаемую карту договоров. Испорченный старый месячный файл
не стирает уже выбранные более новые факты; неподтверждённый fallback
к старому факту запрещён. Ошибки источников явно оставляют расчёт неполным.

## Чтение и видимый результат

Нового HTTP-маршрута, writer или очереди нет: модель собирается в штатном
фоновом просмотре и повторно используется сводкой. Выбор пространства
проекта и алиасов выполняется без создания каталогов. Чтение ограничено
сохранёнными нативными источниками; проверки байтов, пары метаданных,
алиасов и замен источников сохраняются. Полные книги, платёжные строки,
произвольные пути/листы/диапазоны не выгружаются; исходники не переписываются.

В Мониторе четыре cash-плашки стоят сразу после состояния проекта.
Прежние три колонки ФМ перенесены в «Данные ФМ». В HTML/PDF четыре cash-плашки
есть на первой странице; финансовая секция не дублирует эту четвёрку.
Текст сводки использует те же значения. На основных плашках суммы компактны,
точные значения и помесячный охват доступны в расшифровке. Смена проекта,
среза или доступа очищает DOM и сохранённую модель АХР.

Профиль автора первой frozen реализации: 138 passed, 0 failed, 0 skipped,
включая PAGE390/1440, PDF с началом «Стройки» на второй странице,
перекрытие РСС/БДДС, NULL/ноль, возвраты, даты среза, частичные отказы
и сохранение generic reader со всеми месяцами. Это техническое доказательство;
нужны независимая проверка точного итогового HEAD, полный CI и предметная
проверка накопленного результата на уже сохранённых источниках. Исторические
профили86/127PASS относились к прежнему представлению трёх колонок ФМ.
Финансовая готовность, B/P/L и банковское покрытие ими не подтверждаются.
