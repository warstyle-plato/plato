# 999 — административные расходы

Владелец задачи: `finance`. PR: https://github.com/warstyle-plato/plato/pull/999. Актуальные SHA/CI — в registry.json и GitHub.
Стартуй с роли из roles/, корневого AGENTS.md и проверки живого HEAD.

Действующее ТЗ: https://github.com/warstyle-plato/plato/pull/999#issuecomment-6611517129.

Нужны денежная сверка по главам, покрытие АХР графиком, дедупликация факта РСС/БДДС и независимая приёмка. Большинство строк карты не доказывает денежные доли. Безусловное утверждение, что расходы уже включены в дефицит, требует подтверждения.

Ближайший шаг: регрессии двух глав, смешанной карты без долей, графика без АХР и неизвестного покрытия. Затем общий объект сверки с источниками, датами и нераспределённым остатком. Проверить также текст docs/management_report.md. Частная числовая приёмка остаётся отдельной от CI.

Прямого пересечения файлов с исправлением ключа нет. Изменения сводки требуют совместной проверки представления с продажами. Частный восстановленный контекст предоставляет контроль вне публичного репозитория.

Передача: что опубликовано, что локально, доказательства на каком HEAD, блокеры и следующий шаг.
Слияние и выпуск — текущему контролю, а не закрытой старой сессии.

## Продолжение сверки плашек

База продолжения — опубликованный `03f9c589320bd9b6e1f2b7232e075e6a794042ab`;
отдельная ветка `codex/ahr-reconciliation-999`. Требование владельца:
«Бюджет = лимит + оплачено + допфинанс». В сверке явно различаются полный
лимит и доступный остаток. Неподтверждённые части не назначаются фиктивной
доппотребностью ради равенства.

Общий объект сохраняет нераспределённый бюджет/программу, различия графика и
оплат; его плашки и расшифровки читают Монитор и сводка. Исключено распределение
смешанной карты большинством строк. Подключение АХР к заменяющему графику —
по проверенному покрытию точной версии и строки; неизвестность остаётся явной.
По работам нельзя распределять дефицит долями бюджета или называть весь
остаток статьи нехваткой. Формат и границы: `docs/funding_reconciliation.md`.

Контрпримеры и целевой профиль:

```sh
PLAYWRIGHT_BROWSERS_PATH=/tmp/plato1041-browsers REQUIRE_BROWSER=1 \
python -m pytest -q tests/test_funding_reconciliation.py \
  tests/test_admin_expense_reconciliation.py \
  tests/test_the_approved_budget_says_what_it_is_made_of.py \
  tests/test_the_monitor_takes_the_finmodel_as_its_finance_book.py \
  tests/test_inspect_funding_sources.py tests/test_funding_source_dates.py
```

Независимая приёмка точного HEAD требуется отдельно. CORE-файлы в этой
среде не подключены; первичный финансовый gate остаётся BLOCKED. Уже сохранённые
документы повторно не запрашиваются. Следующий инфраструктурный шаг — доверенный
read-only runner/mount, без изменения приложения и без публикации первички.

Уточнение владельца 08.11.2026: общий gap считается от полного утверждённого B
(включая АХР) минус оплаты и доступные остатки лимитов одного состава/даты.
Неполный график/постатейное покрытие не делают известную общую сверку unknown.
Экономические АХР и банковские главы — независимые оси: АХР могут уже входить
в несколько глав РСС. Нельзя объявлять их нефинансируемыми по тегу, повторно
добавлять к собственному дефициту или исключать из B. Перенос классификации
при той же стоимости/оплатах/покрытии не меняет общий gap.

Факт владельца для этого проекта: АХР УЖЕ ВНУТРИ банковской сметы, источник —
конкретные статьи глав 2 и/или 3 РСС. Неизвестен только денежный разрез связи
экономическая строка → статья РСС → глава → сумма/доля/период. Кандидаты карты
сохранены без умножения стоимости и без назначения денежной доли по числу строк.
Банковский состав берётся из явной funding_scope рамки бюджета, не из карты;
полный проект —1–3, явно ограниченный бюджет2–3 не расширяется автоматически.

## Строгие upstream-читатели после независимого ревью

Отдельная копия `plato-task999-fix`, ветка `codex/ahr-strict-readers-999`
от объединённого `d6db04a59cc33b9f0aa7f119dadc99d1b6844771`. Правки ограничены
реальными XLSX-читателями лимитов/оплат и передачей cut в финансовые читатели.
Пустые/невалидные/bool/nonfinite значения не подменяются нулями; будущие
платежи исключаются до суммирования, неизвестные даты целевого состава
сохраняются как неполнота. Дельта оплат ограничена baseline..cut, возвраты
сохраняются. Карта/экономический тег АХР и рамка B/P/L не меняются.

Собственные регрессии: `python -m pytest -q tests/test_funding_strict_source_readers.py`.
Они проходят через учебные XLSX → actuals → _funding_risk, не заменяют внешнюю
приёмку. Повторная независимая проверка назначается контролем на точный SHA.
CORE gate остаётся BLOCKED; частные документы, повторная загрузка и ключ
не запрашиваются; публикация, выпуск и production-команды не выполнялись.

Повтор независимого guard на `425543c8` подтвердил первоначальные три
исправления и нашёл один остаточный completeness-дефект: код РСС платежа
unknown ошибочно считался outside. Следующий локальный commit вводит
tri-state scope без изменения формул: неизвестный код платежа/возврата
сохраняет B и делает paid/gap unknown с source row; явный outside и будущие
платежи продолжают исключаться. Добавлены реальные XLSX counterexamples.

Тот же bounded fix сохраняет unknown в диагностических разницах: обе стороны
payment_difference должны быть известны (включая known_fields.fact),
иначе canonical компонент и настоящая плашка показывают неизвестность,
а не ФАКТ модели минус принудительный RSS0. Общая формула не меняется.
