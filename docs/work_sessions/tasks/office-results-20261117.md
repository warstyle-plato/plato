| Блок жилья → офис | Состояние до | Исправление |
|---|---|---|
| Итог, экономика → решение и экономика собственника | Есть; сравнение стратегий вклинивается перед продуктом | Сохранить ключевые итоги, перенести сравнение после экономики |

| Продукты и выручка → доходы объектов | Неполон: итог ДКП включает места; нет долей и цен типов | Единое раскрытие продуктов и сверка с итогом |
| Стартовые и средние цены → стартовая цена ДКП | Неполон: первая/последняя продажа не раскрыты | Фактические цены расчётных периодов и взвешенная средняя |
| График темпа жилья → годовая выручка/доля продаж | Неполон: нет физических месячных продаж, остатков | Помесячный расчётный план, разные единицы отдельными рядами |
| Структура расходов (график + таблица) → таблица расходов | Неполон: график отсутствует | График из тех же категорий рядом с таблицей |
| Финансирование, поток → кредит объекта, участие собственника | Есть | Сохранить авторитетные ряды и сверить выручку |
| ПФ/эскроу жилья → ДКП/аренда | Неприменим без ДДУ | Не переносить жилые нулевые показатели |
| Жилых аналогов аренды/выхода нет → заполнение, аренда, выход | Есть, по годам | Дополнить месяцами; деньги отделить от оценки удержания |
| Чувствительность и календарь → свои разделы объекта | Есть | Сохранить применимость |
| Допущения → параметры стратегии разбросаны | Неполон | Источники цены/динамики и ограничения рядом с раскрытием |

Проверки и передача будут дополнены по итоговому HEAD. Выпуск — действующему
контролю через обычный процесс; автор не выдаёт независимую приёмку себе.

## Реализованные изменения

- Экран и PDF читают `report.office_results`: физические ряды ДДУ из
  операционной модели, веса и применённый индекс ДКП из симулятора, аренду,
  заполнение и выход из тех же помесячных строк, которые вошли в финансирование.
- Размещение мест — существующие under/over из ТЭП, гостевые исключены
  пропорционально действующей модели. Нулевая/пустая цена типа наследует
  общую цену только по уже действующему правилу, с объяснением источника.
- Периоды между продажами сохранены, графики имеют отдельные единицы;
  таблицы раскрывают физический накопленный объём и остаток, цену и выручку.
  ДДУ прямо подписан как поступления на эскроу. Выход — продажа одного объекта
  в отдельную дату. Без капитализации цена и продаваемый объём выхода не
  подменяются нулём и одним проданным зданием.
- Первая, последняя и взвешенная цена — из периодов расчётного плана.
  Исходная цена и дата показываются отдельно только при отличии. Цена на
  конец расчёта вне реализации не экстраполируется: названо отсутствие такого
  ряда. Применённая динамика, источник и отклонённый профиль раскрыты явно.
- График затрат и таблица используют одни `expense_structure` строки.
  Расшифровки смет ниже не добавляются в итог повторно.
- Для удержания денежные поступления и оценка без сделки разделены и в
  верхних показателях. Прибыль, содержащая оценку, подписана.
- Порядок: решение → объект → доходы → цены/продажи → затраты → финансирование
  → экономика собственника → сравнение → чувствительность → календарь
  → допущения. Тизер сохраняет краткую двухстраничную форму тех же разделов.
