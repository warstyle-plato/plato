# КС-6а: короткие номера актов и единицы работ

В накопительной ведомости подписи `КС2-1`, `КС2-2` и `КС2-3` не
распознавались как номера актов. При повторной загрузке одной ведомости
история сохраняла положительные периоды дважды, теряла подтверждённый
накопительный объём и не передавала работу читателю дат актов.

Один строгий распознаватель короткой подписи используется историей и
читателем дат. Он принимает только целую подпись с номером, без извлечения
чисел из дат, упоминаний или составных номеров. Прежние полные номера актов
в истории сохраняют свою семантику, включая суффиксы. Повторные наблюдения
объединяются только по существующему доказательству семейства ведомости.
Изменённые количества и суммы остаются конфликтами.

Подпись акта не создаёт дату: при отсутствии PDF действует прежнее правило
даты подписания из сводной. Такой результат явно предварительный; если
самого акта нет и в сводной, выполнение остаётся без даты. Исходники,
сохранённые импорты, планы и подтверждённые связи не меняются.

Общий нормализатор единиц также считает `смен`/`смена`, `штук`/`шт` и
`чел-час`/`человеко-час` одинаковыми единицами без пересчёта количества.
Разные единицы, например машино-смена и смена, не объединяются.

Предметная проверка выполняется по исходной книге, двум сохранённым
импортам и штатной диагностике исходников. Их определения совпадают;
проблема воспроизводится при текущем разборе и не требует обновления кэша.
После исправления известные объёмы попадают в сравнение с неизменёнными
планом и документами. Неизвестное разделение работ и материалов остаётся
неизвестным; общая сумма ведомости не подменяет это разделение.
Частные документы и суммы в Git не публикуются.

Проверки: история периодов, сохранённые версии, даты актов, годовое
объединение ведомостей и первичный факт КС-6а; дополнительно реальная
карточка в PAGE на 390 и 1440 px и независимая приёмка точного HEAD.
