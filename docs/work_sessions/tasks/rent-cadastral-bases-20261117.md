## Изменение

Событие смены ВРИ отделено от суммы платежа после льгот. Одиночный расчёт и
очереди читают одну функцию даты; отдельная дата применения новой КС имеет
приоритет над сценарной датой. Нулевой платёж не отменяет переход базы.

Текущая КС суммируется по выбранным арендуемым участкам из сохранённых данных
ЕГРН. Неполный набор не считается полной суммой. Явные ручные значения
сохраняются. Автоматические значения пересчитываются, включая выбор участков.

Будущая КС МО сохраняет точную расчётную сумму из применённого расчёта;
округлённые справочные площадь/УПКС не пересчитывают её в другую сумму Excel.
Происхождение исправлено на расчётную оценку, не на новую запись ЕГРН.

Москва: предварительный сценарий площади × введённый земельный УПКС по
участкам; целевой ВРИ/группа, территория, источник и дата показателя заданы
отдельно. Методика и ограничения: [документ](../../land_cadastral_methodology.md).
Полная официальная модель ГКО этим калькулятором не воспроизводится.
Официальная новая КС вводится отдельно с реквизитами/датой источника.

Excel получает те же базы, событие и происхождение; Москва содержит
редактируемые формулы по участкам. Помесячные начисления сохраняют дневное
разделение при переходе внутри месяца и выходе долей очередей.
Неизвестная новая КС не становится нулём: прежняя база используется только
как явно предварительная оценка, сумма не признаётся подтверждённой.
