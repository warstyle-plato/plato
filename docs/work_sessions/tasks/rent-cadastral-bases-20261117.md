## Изменение

Событие смены ВРИ отделено от суммы платежа после льгот. Одиночный расчёт и
очереди читают одну функцию даты; отдельная дата применения новой КС имеет
приоритет над сценарной датой. Нулевой платёж не отменяет переход базы.

Текущая КС суммируется по выбранным арендуемым участкам из сохранённых данных
ЕГРН. Неполный набор не считается полной суммой. Явные ручные значения
сохраняются. Автоматические значения пересчитываются, включая выбор участков.

Будущая КС МО сохраняет точную расчётную сумму из применённого расчёта;
округлённые справочные площадь/УПКС не пересчитывают её в другую сумму Excel.
Происхождение исправлено на расчётную оценку, не на новую запись ЕГРН.

Москва: предварительный сценарий площади × введённый земельный УПКС по
участкам; целевой ВРИ/группа, территория, источник и дата показателя заданы
отдельно. Методика и ограничения: [документ](../../land_cadastral_methodology.md).
Полная официальная модель ГКО этим калькулятором не воспроизводится.
Официальная новая КС вводится отдельно с реквизитами/датой источника.

Excel получает те же базы, событие и происхождение; Москва содержит
редактируемые формулы по участкам. Помесячные начисления сохраняют дневное
разделение при переходе внутри месяца и выходе долей очередей.
Неизвестная новая КС не становится нулём: прежняя база используется только
как явно предварительная оценка, сумма не признаётся подтверждённой.

## Предметная приёмка сохранённого проекта

Доступ к нормализованной копии получен через штатные `/projects/list` и
`/projects/open` с настроенным административным доступом. Данные и отчёты
сохранены приватно вне репозитория. Повторное чтение подтвердило неизменность
серверной записи по хешу; исходная локальная копия также не изменялась.
Закрытые проверки исходных книг, export/review/reimport/reapply/prepared-index
не переоткрывались.

Реальная схема ГлавАПУ содержит в `recognized` распознанные показатели,
а не только строки кадастровых номеров. Серверный читатель исправлен:
принимает лишь валидные строковые кадастровые номера, как интерфейс;
показатели не становятся идентификаторами участков. Добавлена синтетическая
регрессия формы данных без публикации частного содержимого.

Независимая предметная проверка исходников кода `722d4eb3`:

- 32 профильных теста движка/КС/Excel без пропусков.
- 7 506 проверок сохранённого нормализованного проекта: автоматическая
  текущая КС, пять реальных очередей, исходная неизвестная будущая КС,
  проверочные копии с новой базой, переходом внутри месяца и льготами 0/100%.
- Два полных native export проверены через `xlsx_eval`, по 180 месячных
  колонок каждый, включая самостоятельные пять дат выхода и CAPEX четвёртого
  блока, в котором деньги долей 4+5 складываются один раз.
- Ещё 369 проверок редактируемой оценки по площади в экспортной копии:
  проверочный, явно неофициальный УПКС, 180 месячных колонок движок/Excel;
  очистка показателя возвращает неизвестность.

Авторская проверка настоящего PAGE на этой же копии: 2 passed, без пропусков,
390 `/` и 1440 `/classic`; переход собственности в аренду, автоподстановка
текущей КС, пять очередей, ручная будущая оценка, переход внутри месяца,
льготы 0/100%, очистка и явная неизвестность. Серверная запись не вызывалась;
внешняя сеть заблокирована в стенде. Реальные данные проверены для сохранённой
московской территории; МО дополнительно проверена синтетическими сценариями
из профильных тестов. Проверочные новые значения не объявляются официальной
кадастровой оценкой этой земли.

Полная независимая сверка финансирования всех пяти очередей в четырёх блоках
шаблона не заявляется; проверены именно аренда и её потребители.
