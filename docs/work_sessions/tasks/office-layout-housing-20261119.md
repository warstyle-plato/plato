## Пошаговая сверка

Проверены отрисованные страницы жилья и настоящего сохранённого офисного
проекта с паркингом, полный PDF и двухстраничный тизер. Частные вводные,
суммы и снимки не включены в Git. Таблица описывает установленную структуру,
а не предположения по старым номерам задач.

| Шаг и блок жилья | Офис до исправления | Статус → исправление |
|---|---|---|
| 1. Участок и продукт: ТЭП, участок | После решения | Неполон по порядку → первый раздел; свои площади/гаражи сохранены |
| 2. Итог: экономика проекта | ОПУ в поздней экономике собственника | Неполон → первая карточка «Итога» |
| 3. Ключевые параметры | Отдельные показатели решения | Неполон → вторая карточка «Итога» |
| 4. Удельная экономика | После сметы затрат | Неполон → третья карточка «Итога», исходный жилой DOM-компонент с пятью колонками и базами |
| 5. Очереди проекта | Общие контролы скрыты жилым контейнером | Отсутствует на экране → тот же выбор и сравнение очередей, когда они есть |
| 6. Расходы: график и таблица | После доходов, отдельный цветной график | Неполон → перед доходами; исходный жилой компонент и категории движка |
| 7. Структура затрат по статьям | Сметы, общие расходы, эксплуатация | Есть → подробности следующей карточки расходов; удельная экономика удалена отсюда |
| 8. Доходы: структура выручки | Отдельные продуктовые таблицы и сверка | Есть → первая карточка доходов; типы мест и денежная сверка сохранены |
| 9. Нежильё — стратегия реализации | Самостоятельный раздел | Неполон по порядку → внутри доходов, как условная карточка жилья |
| 10. Темпы и цены продаж | Отдельный раздел | Неполон → внутри доходов; единый рисовальщик жилья/офиса, отдельные единицы, подробная месячная таблица |
| 11. Налоговая база продуктов | В старых подробностях | Неполон → после продаж, перед финансированием; одни строки для экрана/PDF |
| 12. Финансирование | Отдельно кредит, отдельно собственник | Неполон → исходные жилые компоненты кредита/капитала/ПФ/эскроу/БРИДЖа по применимости; доходность и CF собственника здесь же |
| 13. Чувствительность | Общий компонент | Есть → предпоследний раздел |
| 14. Календарный план | Общий компонент | Есть → последний раздел |
| Оговорки и решение | Дополнительные верхние разделы | Неполон → раскрываемые подробности «Итога»; сравнение стратегий в доходах |
| Жилые ВРИ, соцнагрузка, квартиры | Неприменимы к офисному проекту | Не добавляются; исключённые жилые вводные остаются диагностикой, не строкой отчёта |

Оба вида проекта используют один список из восьми разделов: участок и продукт
→ итог → очереди → расходы → доходы → финансирование → чувствительность
→ календарный план. Пустая одноочередная группа, как у жилья, не создаёт
ссылку в оглавлении. Гостиничная рамка сохранена отдельно.

## Примеры до / после

- Экран: удельная экономика из расходов перенесена в третью карточку итога;
  первый экран итогов больше не отодвинут многостраничным раскрытием продаж.
- Полный PDF проверенного проекта: удельная экономика была на страницах
  13–14, теперь на странице 2. В тизере раньше отсутствовала, теперь на
  странице 1. Месячные подробности остаются читаемой многостраничной таблицей.
- График: отдельные синие/коричневые серии заменены общим чёрно-серым стилем.
  Общий responsive renderer сохраняет реальный размер подписей 11 px на
  390 и 1440, переносит оси и крайние даты внутрь графика при resize.
- Тип проекта: удалена только строка про жилые остатки. Исключение этих
  вводных из расчёта и их сохранение при возврате к жилью не изменены.
