# 1042 — проценты всех загруженных договоров и динамика

Работа продолжается: [задача](https://github.com/warstyle-plato/plato/issues/1042),
[PR 1046](https://github.com/warstyle-plato/plato/pull/1046).
Ветка: `codex/contracts-ledger-followup`. База: `2061d1a0`.
Контроль — текущий разговор владельца в Codex, по `CONTROL_ACTIVE`.

## Требование владельца

Все договоры и подрядчики из загруженных документов должны быть видны с
известными процентами выполнения. КС-6а и денежное закрытие КС-2 по сводной
сохраняют разные основания. Те же квалифицированные цифры используются в
динамике. Повторная загрузка уже сохранённых файлов не требуется. Основой
ГПР служат утверждённый ГПР и КС, MS Project не используется.

## Результат первого этапа

- Договор с известными стороной и номером остаётся в рабочем блоке при
  ошибке в дате. Дата требует уточнения и не разрешает опасный join с РСС.
- Старый импорт перечитывается в памяти из архива с проверкой SHA, без
  изменения исходников, идентификаторов и ручных решений.
- План работы учитывается один раз, годовые факты объединяются только при
  доказанной общей базе. При конфликте видны известные проценты источников
  и конкретная причина отсутствия общего итога.
- Карточка, история и потребители получают один квалифицированный показатель.
  Даты наблюдений не выдаются за даты выполнения работ.
- Сохраняются разделы, участки и явно подписанные стоимости СМР для
  последующей доказуемой связи с работами ГПР.
- Объединённая шапка стоимости разрешается по структуре и формулам исходника,
  без выбора первого подстолбца. СМР, материалы и общая стоимость различаются.
- Исходные копии строк исключаются только при точном совпадении и явном
  исключении обеими формулами итогов. Строки, ID и ручные связи сохраняются.
- Договорные секции сводной не теряются. Различающиеся реквизиты остаются
  отдельными источниками до уточнения; число источников не выдаётся за число
  доказанных уникальных правовых договоров.

## Приёмка и оставшаяся работа

Владелец предоставил полный исходный архив и корпусный ГПР. Архив совпадает
с сохранённым в системе. Независимая сверка первичных ячеек выявила ошибки,
не обнаруженные прежними проверками двух файлов; они исправлены отдельными
итерациями с регрессиями. Выполняется окончательная приёмка объединённого
HEAD: исходные значения и итоги, прежние импорты/ID/ручные связи, история,
видимые карточки и отчёты. Проверки синтетики не подменяют этот результат.

Неизменяемый прежний валидатор и предметные доказательства рассматриваются
вместе: исправленная исходная ошибка или доказанное исключение копии должны
быть объяснены, а не сохранены ради прежнего ошибочного числа. Частные
исходники и финансовые доказательства хранятся вне репозитория.

Интеграция источников КС с реальным корпусным ГПР продолжается в #1047.
Общая задача остаётся открытой до проверки всех потребителей и фактического
результата. Неизвестные связи участков не подтверждаются автоматически.

Выпуск — только после независимой приёмки точного HEAD и обязательного CI,
штатным workflow по [AUTO_RELEASE](../AUTO_RELEASE.md). Сам PR, зелёный CI
или допуск очереди не подтверждают фактический прод и завершение всей задачи.
