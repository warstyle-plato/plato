# Ограниченное подтверждение исходных ячеек АХР

Срочное поручение действующего контроля Codex в существующем #1019.
Ветка `codex/ahr-source-proof-20261113` от main b40fb16d. Поддержка чтения
выпускается отдельно от PR1105 и не включает его виджет или финансовый
расчёт. Автор не выполняет выпуск и не принимает собственный патч.

Причина: сохранённые receipts не подтверждают обработку реальной книги,
а существующий `/monitor/audit/sources` отдаёт целые финансовые источники.
Bulk-выгрузка не повторялась. Новый фиксированный профиль не принимает
имена файлов, листов, ячейки, диапазоны, URL или содержимое источников.

Два нативных скрытых маршрута:

- POST `/monitor/audit/admin-expenses`: только `project`, `cut`, необязательный
  `ticket`, `session` и обязательный действующий ключ администратора `key`.
- POST `/monitor/audit/admin-expenses/result`: `ticket`, `session`, `key`.

Оба маршрута проверяют строгий ключ администратора, даже без токена бота.
Демо/рынок/группа сами доступа не дают. Тело ограничено12KiB; лишние поля,
дубли JSON-ключей и неверные даты закрыты. Долгий XLSX-разбор работает в
существующем disk-backed jobs, с привязкой к владельцу/сессии/профилю,
идемпотентным ticket и отзывом доступа после смены ключа. Ответы private,
no-store; входные ключи и источники не записываются в метаданные задания.

Выход — только листовые коды2.4 без налогов2.4.5, координаты и исходные
cached значения трёх граф «ИТОГО/ФАКТ/ПЛАН», признак формулы без её текста,
тип значения и bounded provenance: дата версии, SHA256 книги/метаданных,
снимок runtime, UTC-время чтения. Имен расходов, оригинальных имён файлов,
формул, base64 и URL в ответе нет. Нет денежных сумм по группам или
пересчёта единиц. Единицы подтверждаются только токенами в фиксированной
шапке до граф «ИТОГО/ФАКТ/ПЛАН»: координата, исходный токен и распознанная
шкала. Нет токена — missing, разные шкалы — ambiguous; рубли на квадратный
метр не принимаются за шкалу денежных граф. Ограниченный context содержит
только координаты/типы/хэши шапки, без произвольных значений. Это
доказательство источника, не financial acceptance.

Источник выбирается из уже существующего проекта через native namespace
и однозначные aliases, без создания новых каталогов проекта. Чтение
ограничено16MiB и128MiB распакованной книги,20000строками,1000колонками,
400листовыми строками,256KiB ответа. Полный набор не обрезается молча.
Symlink/hardlink и смена namespace/source закрыты. Общий baseline flock
согласован с обоими native finance writers; source-bound метаданные и
атомарная публикация не дают выдать новые байты за прежнюю дату.

Будущая или недатированная версия не выдаёт исторические денежные строки.
Старые метаданные без source SHA поддерживаются с явным признаком
`metadata_bound_to_bytes=false`, не превращаются в криптографически
подтверждённую связь. Остаток полной банковской приёмки #1045 не закрыт.

Авторские проверки:48 новых тестов без пропусков — raw cache без расчёта,
формула с сохранённым cache, ноль/unknown/boolean/error, дата/SHA, aliases,
symlinks/размеры, два процесса и paused writer, прерванная публикация,
strict admission/owner/rotation/body и отсутствие запуска виджета.
Соседний профиль audit/jobs/финансовых дат/baseline:199passed,
15браузерных проверок отдельно выполнены в профиле jobs:26passed,
обязательный Chromium, без пропусков.

Реальная финансовая книга по новому маршруту ещё не читалась. После
независимой security/data-read приёмки и штатного выпуска контроль
однократно читает существующую ФМ, сохраняет маленький приватный source
proof и независимо сверяет его с плашками1105. Частные значения не
публикуются в GitHub, CI-артефактах или публичной карточке задачи.

После независимой security/data-read проверки уточнены три границы:

- В `cached_value` остаются только конечные числа и ограниченные строковые
  числовые представления. Текст, ошибки, boolean/date и прочие типы
  возвращаются как null с типом и SHA256, без исходного содержимого.
  Настоящий числовой ноль сохраняется; unknown не становится нулём.
- Шапка обрабатывается потоком: не более80строк,32768символов в ячейке
  и65536символов суммарно. В процессе сбора хранится максимум64token-dict,
  а отдельное множество шкал обнаруживает ambiguous даже после заполнения
  списка. Границы проверяются до нормализации или сохранения текста.
- Подписи «за/на [1] м²/м2/кв.м», площадь, гектар и место не принимаются
  за глобальную шкалу денежных граф, как и прежние slash-варианты.

Итоговая авторская регрессия:81passed, без пропусков; два независимых
synthetic repro также проходят (83passed вместе). Маленький30000-символьный
пример6000повторных токенов хранит64записи, измеренный peak21411bytes
при4829bytes JSON. Нагрузки/OOM и чтения реальной книги не выполнялись.
Новый коммит требует повторной независимой проверки точного SHA.
