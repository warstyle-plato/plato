# 1030 — договоры в работах и короткие ответы по накопительным

PR: https://github.com/warstyle-plato/plato/pull/1030.
Продолжение открытой ветки `claude/monitor-contract-risk-signals` от
`4d53169caebcae257805fd29ed38458a4d449fe1` по поручению владельца.
Рабочая копия исполнителя: отдельный worktree и ветка
`codex/cumulative-work-contracts`.

## Изменения

- Единственный подходящий договор точно названного подрядчика определяется
  без ручного подтверждения. Несколько договоров требуют выбора; другой
  указанный номер, несовместимые корпуса, дата договора после сообщения
  не разрешают автоматическую связь.
- Точное имя при атрибуции работ имеет приоритет над похожим именем из
  списка. Одинаковое название без правовой формы не разрешает выбор между
  несколькими юридическими лицами.
- Таблица работ сводки читает из реестра денежную долю накопительных и
  прогноз задержки. Неизвестное значение не заменяется нулём. Доля всего
  договора не называется натуральной готовностью отдельной работы.
- Основной вид договоров сокращён до ответов о выполнении и сроках.
  Подробные источники и расчётные основания доступны по раскрытию.

## Приёмка

Профильные проверки и независимые контрпримеры проводятся на синтетических
данных. Числа и соответствия закрытого производственного архива этим
прогоном не подтверждаются. Слияние и выпуск не выполнялись.
После публикации нужен полный CI текущего HEAD.
