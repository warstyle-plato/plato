# Договоры: исправления по приёмке

Поручение владельца: устранить замечания к блоку договоров после проверки
PR #1195. Исходная проверка — `ea68b4e`; к началу исправлений PR уже был слит.
Ветка `codex/contracts-acceptance-fixes-20261118` создана от main `9215cda2`.

Прошедший срок показывается во «Внимании» и следующем действии независимо
от охвата сопоставления. Отдельное предложение сверить КС-6а сохраняется.
Отметка даты не утверждает неисполнение договора.

Повторные неполные наблюдения КС-6а имеют устойчивое имя с учётом реквизитов,
контекста, области и исходных противоречий. Все версии остаются в истории;
неизвестные объёмы не становятся подтверждёнными. Если в одной книге есть
несколько неразличимых строк, их имена не доказывают тождество: повтор
определяется только по тем же байтам книги и той же исходной строке.

Неподтверждённый скан КС-2 назван сканом с неподтверждёнными значениями,
а отсутствующим — только действительно отсутствующий акт из датированной
сводной. Непрочитанные акты сохраняют свою причину исключения из расчёта.
