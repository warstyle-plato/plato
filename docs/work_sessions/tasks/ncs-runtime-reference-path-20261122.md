# Справочник НЦС вне каталога состояния

Неизменяемый справочник НЦС-2026 поставляется вместе с кодом в
`reference_data/education_ncs_2026.json`. Каталог `data/` предназначен для
состояния и монтируется постоянным диском; файлы из новой сборки под ним
могут быть скрыты содержимым диска. Docker также исключает `data/` из образа.

`education_ncs.py` читает упакованный справочник. Серверный подбор ставки,
`mo_vri_benefits.catalog()` и встраивание каталога в настоящую `PAGE` получают
один источник. Байты JSON и методика расчёта не меняются. Данные проектов,
состояние, прежний нормативный реестр и механизмы восстановления не меняются.

Регрессионная проверка запускает новый процесс с отдельной копией модуля и
упакованного справочника: `data/` отсутствует, пуст либо содержит устаревший
файл НЦС. Проверяются ставка, оценка льготы и JSON в настоящей собранной `PAGE`.
Остальные модули и прежний нормативный реестр берутся из рабочей копии;
проверка не утверждает запуск всего приложения без его прежних справочников.

Команда: `python -m pytest tests/test_ncs_runtime_packaging.py
tests/test_mo_vri_education_ncs.py tests/test_mo_vri_benefits.py -q`.
Приёмка точного HEAD выполняется независимо перед выпуском.
