# Telegram: итог разбора после последнего ответа

Исполнитель: Codex. Действующий контроль и независимая приёмка: Claude, #1019.
Ветка: `codex/teaser-last-answer-20261113`, база main `29a9fc04`.

Владелец сообщил: после ответа на последний вопрос о классе жилья бот
подтверждает ответ и замолкает. Статус действующего Render-бота подтвердил
HTTP400 Telegram: незакрытый тег `i`. В пути отправки карточки HTML обрезался
как строка на 4000 символов. Состояние ответа записывалось до этой ошибки.

Карточка теперь отправляется полностью ограниченными частями, с закрытием и
восстановлением форматирования и без разрыва entity/Unicode. Кнопка расчёта
прикрепляется только к последней части. Аналогично отправляются первая
карточка и вопросы разбора. `/calc` показывает возврат к уже сохранённому
разбору, в том числе после попадания следующего нажатия в другой воркер.
Верхний обработчик сообщает ошибку кнопки в личный чат; группы и отказы429
сохраняют прежний запрет дополнительных сообщений.

Регрессия воспроизводит исходный отказ на синтетической длинной карточке
после выбора «Элитный»: незакрытый `i`. Проверки удерживают полный текст,
кнопку, выбранный класс в сессии, сохранённые ответы и отсутствие запуска
расчёта до подтверждения. Производственные документы, токены и содержимое
частных разговоров в тесты и GitHub не передаются. Модельные запросы и
отправки сообщений пользователям в ходе проверки не выполняются.
