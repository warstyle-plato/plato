# Образцы офисной модели (утверждены владельцем 22.10.2026)

- `office_book_v4_sample.xlsx` — образец книги офиса на каркасе жилой v4:
  Дашборд, ОТЧЕТ, Вводные, ИНСТРУКЦИЯ, СРОКИ, CAPEX, Ставки, Продажа, Аренда,
  Выход, CF_Продажа, CF_Аренда, ПРОВЕРКИ. Месяцы вправо (D5 закреплено),
  ~10 тыс. формул; «ПРОВЕРКИ» — 20/20 итогов совпадают с движком на данных
  Пролетарского пр., вл. 20. Значениями из движка пока: график CAPEX,
  ключевая ставка, налог на прибыль (в рабочей книге — листы формул).
  Владелец: «Да, делай» (вариант «На каркасе жилой v4»).
- `office_teaser_report_sample.pdf` — образец тизера (стр. 1–2) и ключевых
  страниц отчёта (стр. 3–6), два пути рядом. Владелец: «отчет ок».
- `make_book_v4_sample.py`, `make_teaser_report_sample.py` и помощники
  `run_office.py`, `collect.py`, `be.py` — генераторы образцов. Пути к
  scratchpad внутри — от сессии, где их писали; поправить при запуске.

Числа образцов — на шкале класса до решения 22.10 (аренда 2,5 тыс. ₽/м²/мес.,
цена 273, стройка 110): шкала с тех пор — `docs/office_two_paths.md`.
Устройство и решения: `docs/office_two_paths.md`.
