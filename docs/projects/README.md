### Как загрузить на developaid.ru

1. Открыть developaid.ru, наверху нажать «Личный кабинет».
2. В окне нажать «Загрузить файл настроек» и выбрать этот `.json`.
3. Подтвердить «Загрузить настройки «77:01:0006018:75 — отчёт 09.09.2026»?».
   Страница подставит вводные и ТЭП и сама откроет отчёт.
4. Чтобы проект пережил смену браузера — там же «Сохранить как…» (нужен вход).

из файла не наполняется: сохранение туда — только кнопкой после входа.
