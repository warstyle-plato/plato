## 4. Схема процентов (месяц; E — эскроу ДДУ, K — долг, A — аккредитивы)
А: c = E/(K_А−A_А); c<1: I_А = [A_А·2,02 + E·4,26 + (K_А−A_А−E)·(КС+4,78)]/K_А; c≥1: I_А = [A_А·2,02 + (K_А−A_А)·I(v)(c)]/K_А.
Б (допущение): F_Б = E·(K_Б−A_Б)/(K_А+K_Б−A_А−A_Б); c_Б = E/(K_А+K_Б−A_А−A_Б); c_Б<1: I_Б = [A_Б·0,7 + F_Б·4,75 + (K_Б−A_Б−F_Б)·(КС+4,14)]/K_Б; c_Б≥1: I_Б = [A_Б·0,7 + (K_Б−A_Б)·I(v)(c_Б)]/K_Б.
Сверху: 0,7 % от свободного лимита до конца доступности (А 30.06.2027, Б 30.09.2027); при отсрочке — проценты на капитализированные по базовой; выплата А 30.09.2027, Б 30.03.2029 или раньше при закрытии всех эскроу; надбавки.
