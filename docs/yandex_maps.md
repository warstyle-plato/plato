# Карта «Схема / Гибрид» и ключ Яндекс Карт

## Что где видно

- **Схема** — карта улиц OpenStreetMap. Её склеивает сервер (`/land/basemap`,
  тайлы `OSM_TILE_URL`). Она уходит в PDF, в печать кабинета рынка, на первую
  страницу отчёта и в бот.
- **Гибрид** — снимок со спутника с улицами и подписями от Яндекса. Он есть
  только на живой карте страницы (`openLandMap` в `engine/page_js_land.py`):
  у карточки участка, на карте КРТ, у Нагатино, у лота, в кабинете рынка
  («Где соседи» → «Открыть живую карту») и в новом интерфейсе участка (кнопка
  «Гибрид» на карте окружения, скрипт `/land/live-map.js`).

## Почему гибрида нет в PDF и в боте

- Серверные API Яндекса (Static API, Tiles API) отдают только схему, снимка и
  гибрида у них нет.
- Условия использования API Яндекс Карт (п. 5.1.2 и 5.1.6) запрещают сохранять
  и видоизменять полученные данные. Кэш разрешён только для работы сервиса и
  не дольше 30 дней.
- Поэтому `/land/basemap?layer=hybrid` отвечает 422 с этой причиной, а не
  подставляет карту улиц молча.

## Ключ

- Переменная окружения **`YANDEX_MAPS_API_KEY`** задаётся на ядре (Яндекс).
  Render спрашивает ядро через `/land/basemap-views`. Можно задать ключ и на
  Render: тогда он ответит сам.
- Ключа нет — кнопка «Гибрид» неактивна, а под картой написана причина.
  Ядро не ответило — тоже названная причина.
- Ключ JavaScript API по природе браузерный: Яндекс грузит карту по нему в
  браузере посетителя, поэтому он виден в адресе скрипта. Его защищают не
  тайной, а ограничением **по HTTP Referer** в кабинете разработчика: впишите
  туда домены сайта, и с чужого сайта ключ работать не будет. В журнал
  сервера значение ключа не пишется.

## Как владелец получает ключ

1. Кабинет разработчика: <https://developer.tech.yandex.ru/> → «Подключить
   API» → **«JavaScript API и HTTP Геокодер»**.
2. Сайт платный (доступ к расчёту за деньги), поэтому бесплатные условия
   (п. 4.1.1: «Сервисы не могут использоваться в проектах, требующих оплаты»)
   не подходят. Нужна **коммерческая лицензия JavaScript API**: тариф выбирают
   по числу загрузок карты в сутки на <https://yandex.ru/maps-api/products/js-api>
   (на октябрь 2026 — от 195 000 ₽ в год за 500 загрузок в сутки).
3. В настройках ключа ограничить его доменами сайта (HTTP Referer).
4. Записать ключ в `YANDEX_MAPS_API_KEY` на ядре и перезапустить ядро. Ключ
   включается у Яндекса в течение 15 минут после выдачи.

## Проекция

Тайлы Яндекса лежат в эллиптическом меркаторе (EPSG:3395), а контуры ЕГРН у нас
в сферическом (EPSG:3857). Контур передаётся в Яндекс широтой и долготой
(`landMapGeo`, обратная формула той же сферы), а проекцию считает сам API. Свою
проекцию карте Яндекса не задаём. Проверка — `tests/test_the_map_offers_a_yandex_hybrid.py`.
Она падает, если подменить формулу или задать карте другую проекцию.
