# Корпуса в исходных объёмах КС-6а

Исходная таблица карточки делится на корпуса и объекты по явному полю участка
каждой позиции. Объект определяет тот же читатель, который используется в
сравнении с ГПР. Несколько корпусов или отсутствие объекта дают отдельный
раздел «Корпус или объект не определён»; соседняя строка не задаёт привязку.

Полный исходный участок с этажами сохраняется под заголовком корпуса.
Пользователь может выбрать корпус или объект и найти работу по индексу
либо названию. Состав строк, номера источника, объёмы, материалы и замечания
сохраняются; порядок исходных строк внутри корпуса остаётся прежним.
Группировка меняет представление, а не сумму или выполнение.

Таблица исходных КС-6а и накопленный план-факт — разные поверхности.
Выгрузка накопленного план-факта сохраняет его собственные заголовки корпусов
и отдельные операции. Отдельной выгрузки исходной таблицы КС-6а эта правка
не добавляет.
