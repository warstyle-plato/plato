# Эталонные числа (golden)

Сторож молчаливых изменений экономики. Тест
`tests/test_golden_numbers_do_not_move_silently.py` пересчитывает восемь эталонных
проектов и сравнивает ключевые числа с `*.json` здесь. Любое изменение ломает тест.

Эталоны (`scripts/golden_snapshot.py`, `SCENARIOS`):

| файл | проект |
|---|---|
| `default` | страница по умолчанию |
| `nagatino_phased` | КРТ Нагатино, пресет `presets/КРТ_Нагатино.json`, очереди |
| `mixed_osz_parking` | жильё + ОСЗ-офис, гараж 200 мест под землёй и 40 на первых этажах |
| `retail_sports` | ТЦ + ФОК на продажу, у обоих гаражи |
| `nonresidential` | нежилой проект (один офисник) |
| `instances` | вторые экземпляры офиса и ТЦ в двух очередях |
| `legacy_state` | состояние, сохранённое выпуском 0.24.56 (`legacy_state_inputs.json`), поверх текущих умолчаний |
| `krt_catalog` | скрининг КРТ «Варшавское ш., вл. 37» из каталога при зафиксированном рынке |

Что держится: ТЭП по строкам (ГНС, продаваемая, передаётся, места), выручка по
продуктам, CAPEX по статьям, итоги (`summary`: LLCR, NPV, IRR капитала, прибыль,
маржа), финансирование, строки отчёта (продукты, структура затрат, финансирование);
по очередям — итоги и ТЭП каждой.

## Если тест упал

1. Прочитайте, какие числа сдвинулись (тест печатает путь и «было → стало»).
2. Сдвиг не задуман — это регресс, чините код, снимок не трогайте.
3. Сдвиг задуман — обновите снимок **отдельным коммитом**:

   ```
   python3 scripts/golden_snapshot.py --update --reason "что поменялось и почему"
   ```

   Скрипт перепишет `*.json` и допишет строку в `CHANGES.md` (отпечаток снимков,
   выпуск, число сдвинутых чисел, причина). Ту же причину — строкой в описание PR:
   `Эталоны: <причина>`.

Руками `*.json` не правят: тест сверяет отпечаток снимков с последней строкой
`CHANGES.md` и падает, если снимки меняли без `--reason`.

`legacy_state_inputs.json` — вход, а не результат: его не обновляют вместе со
снимками.

Прошлые выпуски снимаются тем же скриптом: `--root <git worktree> --out snap.json`.
