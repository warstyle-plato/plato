# Посадка на участок и ёмкость

Цель — быстро и честно ответить: что и сколько можно построить на участке, с вариантами посадки и ТЭП. Это скрининг ёмкости, а не проект: нормативные расчёты инсоляции, КЕО и пожарных рисков делаются в специализированном ПО и проектировщиком. Об этом — одна строка в выводе, без лишних оговорок.

## 1. Определить режим

**Режим А — есть ГПЗУ (или ППТ).** Параметры заданы документом, задача — вписать максимум.
**Режим Б — голый участок** (кадастровый номер, контур, тизер). Параметры надо вывести самому и дать сценарии.

Если есть и то и другое — режим А, а режим Б использовать для проверки, не занижены ли параметры ГПЗУ.

## 2. Сбор исходных данных

Общее для обоих режимов:
- Контур участка: координаты поворотных точек (выписка ЕГРН, схема, DWG/PDF). Если координат нет — запросить у пользователя; до этого работать по площади и примерной форме с пометкой «допущение».
- ЕГРН / ПКК: площадь, категория, ВРИ, обременения.
- ЗОУИТ, ОКН и их зоны, охранные зоны сетей, санитарные разрывы, красные линии, соседняя застройка (высота, расстояния — для инсоляции и разрывов).
- Москва — ИАИС ОГД / mos.ru, МО — РГИС. Если источник недоступен, не обходить, а внести в список «что запросить».

**Режим А — из ГПЗУ выписать:** зону допустимого размещения, предельную высоту / этажность, максимальный процент застройки, плотность или предельную площадь (тыс. м² / СПП / ГНС), назначение, требования к соцобъектам и парковке. Сразу отметить расхождения ГПЗУ с ПЗЗ, если видны.

**Режим Б — вывести параметры:**
- Территориальная зона и индексы ПЗЗ (Москва — индексы плотности, высотности, процента застройки; МО — параметры ПЗЗ муниципалитета).
- Аналоги: ГПЗУ и ППТ соседних участков, параметры ближайших ЖК.
- Нужно ли изменение ВРИ, КРТ или ППТ — отдельной строкой со сроками и риском.
- Дать три сценария: **консервативный** (по действующим ПЗЗ), **базовый** (по аналогам), **максимум** (с изменением параметров — указать, что для этого нужно).

## 3. Посадка

Геометрию считать в коде (Python, shapely), не «на глаз»:
1. Пятно допустимого размещения = контур минус отступы, красные линии и зоны ограничений.
2. 2–3 варианта посадки: секционная застройка, башни, квартал или периметр — по тому, что подходит форме участка и высотности.
3. Для каждого варианта: пятна корпусов, этажность по корпусам, пожарные проезды, разрывы между корпусами, двор, место под паркинг (подземный / наземный) и соцобъекты, если требуются.
4. Схему показать прямо в чате (SVG): контур, отступы, корпуса с подписью этажности, проезды, север.

Ориентиры (сверять с действующими редакциями норм через поиск, а не брать из памяти):
- Инсоляция — СанПиН 1.2.3685-21; для центральной зоны (48–58° с. ш., Москва и МО) — не менее 2 ч непрерывно в период 22 апреля – 22 августа. На скрининге — грубая проверка теней по геометрии и углам солнца; риск отмечать по корпусам.
- Пожарные проезды и разрывы — СП 4.13130; ширина проезда и расстояние до стены зависят от высоты здания, при высоте более 28 м требования жёстче.
- Градостроительные нормы — СП 42.13330, региональные нормативы (РНГП Москвы / МО) — для парковки, соцнагрузки, площадок.

Конструктивные допущения (если пользователь не дал свои — взять из диапазона и вынести в таблицу допущений): ширина корпуса для секций и для коридорных схем, высота этажа (жилой, первый коммерческий), коэффициенты ГНС → СНП → продаваемая площадь.

## 4. ТЭП

По каждому варианту и сценарию, в одной таблице:
- Площадь участка, площадь застройки, процент застройки.
- ГНС (наземная / подземная), плотность, этажность по корпусам, высота.
- Продаваемая площадь: жильё / коммерция / кладовые; квартирография (если задана — по ней, иначе типовая для класса с пометкой).
- Машино-места: требуемые по нормативу и размещаемые; дефицит — красным флагом.
- Соцнагрузка: места в ДОУ / СОШ / поликлинике по нормативам — разместить или компенсация.
- Проверки: процент застройки, плотность, высота, инсоляция (риск), проезды, парковка — статус «ок / риск / нарушение».

Всю арифметику — в коде. Результат, который пользователь сохранит или передаст, — таблица в Sheets (если тип доступен; иначе .xlsx).

## 5. Вывод

1. Ответ в двух строках: ёмкость участка (продаваемая площадь в базовом сценарии и вилка), рекомендуемый вариант посадки.
2. Схемы вариантов.
3. Таблица ТЭП и проверок.
4. Что ограничивает ёмкость сильнее всего (высотность, инсоляция, парковка, отступы) и что даст прирост.
5. Что запросить или проверить: ГПЗУ, ТУ, топосъёмка, ИГИ, заключения по ОКН.
6. Блок **«Вход для invest-screening»**: ГНС, продаваемая площадь по типам, машино-места, соцнагрузка, сроки на изменение параметров — чтобы сразу передать в инвест-скрининг.

## Правила

- Не выдумывать параметры ПЗЗ, ГПЗУ и норм: только найденное, с источником; остальное — допущение с пометкой.
- Нормативные значения брать из действующих редакций; если не удалось проверить — сказать об этом.
- Если пользователь поправляет методику или допущение — принять, отозвать прежний вывод, пересчитать.
- Отдавать рабочий результат быстро, дорабатывать по обратной связи; минимальная палитра, без цветного шрифта.
