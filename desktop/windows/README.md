# DevelopAid для Windows — первый прототип

Основа прототипа обновлена до main после добавления накопительных и сверки договоров.
Клиент использует серверную версию, показанную на сайте.
Клиент открывает https://developaid.ru/ в отдельном окне. Версия интерфейса
и расчёта соответствует реально развёрнутому серверу: исходный коммит не
фиксирует серверную версию. Приложению требуется интернет.

## Запуск

Windows 10/11 x64 и установленный Microsoft Edge WebView2 Runtime.
Распакуйте весь архив DevelopAid-Windows-x64.zip в отдельную папку и запустите
DevelopAid.exe. Папка _internal должна оставаться рядом с exe.
Python пользователю готовой сборки не нужен. Сборка пока не подписана.

Используется существующий вход на сайте и те же права доступа. Cookies и
локальные данные сохраняются отдельно от браузера в
%LOCALAPPDATA%\DevelopAid\WebView2. В меню есть возврат на главную и открытие
сайта в браузере. Внешние веб-ссылки открываются через HTTPS; ссылки на локальные
файлы и произвольные протоколы операционной системы не передаются браузеру.
Та же политика применяется к навигации внутри WebView2; запуск внешних
протоколов отменяется. Если обработчики защиты установить не удалось, окно закрывается.
При потере сети WebView2 показывает сетевую ошибку; после
восстановления соединения выберите «Открыть главную».

## Сборка из исходников

На Windows с Python 3.12 x64 выполните `powershell -File desktop/windows/build.ps1`
из корня репозитория. Результат — desktop/windows/dist/DevelopAid-Windows-x64.zip.
В GitHub Actions workflow Windows desktop также собирает архив на Windows.
Он также запускает настоящий WebView2 на синтетической локальной странице:
проверяет запуск, отсутствие пользовательского Python API и сохранение данных
после повторной навигации, а также отказ файловым и внешним протоколам. Эти проверки не заменяют приёмку рабочих сценариев
на Windows. Workflow не публикует релиз и не развёртывает сервер.

Перед удалением временного профиля smoke-проверка ждёт до 15 секунд завершения
своего браузерного процесса: его дескриптор получен из WebView2 с этим профилем.
Если процесс не определён или не завершился, проверка падает и сообщает путь
сохранённого профиля. Ошибки очистки не скрываются, другие процессы не завершаются.

## Приёмка на настоящем Windows

- Запуск на чистом компьютере с WebView2, понятная ошибка без Runtime.
- Вход через действующий механизм сайта и сохранение входа после перезапуска.
- Ввод адреса/кадастра, ТЭП и расчёт экономики жилого и нежилого проекта.
- Сохранение проекта и восстановление после перезапуска.
- Экспорт Excel и PDF, проверка содержимого скачанных файлов.
- Внешние ссылки, Telegram-вход, оплата и возврат в приложение.
- Потеря сети и восстановление, масштаб Windows 125% и 150%.

До выполнения этих проверок прототип нельзя считать готовой Windows-версией.
Автономный движок, установщик, подпись и обновление самого exe в этот этап
не входят. Обновления сайта появляются при следующей загрузке страницы.
