# Монтажные исходники старой сессии (серия 1, версия 7.7, 8:56)

Состояние на 03.11, ночь. Это сборка, опубликованная на странице замечаний как «версия 7.7 · 8:56» (папка видео `v77c/`).

## Как собрать
Все пути считаются от папки проекта E (здесь — `old_session/`); шрифты ищутся в `../fonts`, поэтому скопируйте `fonts/` на уровень выше E или поправьте строку `YES/NUN` в скриптах.

    E=$PWD
    PART=1 python3 build.py $E      # часть 1 (сегменты в build.py)
    PART=2 python3 build.py $E      # часть 2 (сегменты в seg2.py)
    PART=3 python3 build.py $E      # часть 3 (сегменты в seg3.py)
    python3 final.py $E             # склейка: часть 1 + 2 + 3 + финал + крючок + анонс

- `ONLY=s5,s8c PART=1 ...` пересобирает только перечисленные сцены, остальные берёт готовыми из `out*/`. При первом запуске `ONLY` не задавать.
- Одну и ту же часть никогда не собирать двумя процессами одновременно: портятся файлы.
- `out/opening.mp4` — готовая заставка (её делает `opening.py`).
- `cs4/shift.json` — сдвиг начала клипа под губы (положительное значение: пропустить начало); `cs4/mouthpos.json` — где рот в кадре (для проверочных полос).
- Сегмент: (id, "vid", [(клип, начало, длительность), ...], пауза, [(реплика из a/, смещение), ...], фоновый шум, ...). PNG в списке получает медленный наезд.
- Шумы мест: `sfx_norm/` (выровнены к −25 LUFS). Музыка полностью стихает на улице/в аэропорту/на взлёте и звучит вполголоса под остальными диалогами (`NOMUSIC`, `MUSIC_ON`, `HALF` в build.py).
